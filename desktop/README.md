# 运气通 Windows 离线侧栏样机

适用于 Windows 10/11 x64。安装程序使用当前 Windows 用户目录，随包提供 WebView2 完整离线安装器、内嵌 Rust 规则引擎与 React 工作台。院内试用的安装包和 SHA-256 在交付目录内。安装介质应按院内软件管理流程分发。

## 诊室试机

1. 将安装包复制到电脑本地，双击安装。从开始菜单启动“运气通”。
2. 按住“运气通”标题或旁边的空白处，将窗口拖到要使用的位置后松手。程序记住位置，医生站可继续使用整个工作区。拖到靠近工作区顶部的位置松手，鼠标连续离开达到 350 ms 的判定阈值后窗口收成窄边，移到窄边即可展开。拖动标题离开顶部后恢复自由摆放。
3. 点亮图钉后窗口持续置顶，贴顶隐藏暂时关闭。再点一次恢复置顶前的状态：原先自由摆放的窗口继续浮动，原先贴顶的窗口恢复自动隐藏。如果置顶期间拖动标题换了位置，取消置顶后留在新位置；只调整高度或主题仍可恢复原先的停靠。托盘可直接切换“允许贴顶自动隐藏”。标题栏收起按钮仍可切换至胶囊。
4. 断网后，用合成日期试“当下运气”“指定时点”“先天对照”。如需测试量表，提交一份合成答卷，再选“结束并销毁答卷”。回到先天对照可以清空本次资料。切换页面和收起保留当前会话，退出程序结束会话。检查低分辨率和高缩放下的底部按钮、拖动位置和顶部感应条。
5. 记录 Windows 版本、缩放、安装或使用失败的步骤和画面。提交试用反馈时使用合成资料。

计算由同一 Tauri 进程中的 yunqi-core 及 tyme4rs 提供。工作台通过 Tauri IPC 调用 10 个业务操作，系统时钟为“当下”提供时间。拖动展开窗口底边可调高，或聚焦底边后按上下方向键。高度基准为 680，默认 1020 个逻辑像素；小屏按实际可用空间显示。浮窗的首选高度、显示器和位置、贴顶设置、图钉偏好与每屏的胶囊位置保存在该用户的应用配置目录。医疗输出维持规则学习与教学展示范围。

## 离线字体

从 0.2.3 起，工作台的黑体和宋体优先使用本地常用字库。两份字体合计 708,960 字节，覆盖 1,119 个常用码点。遇到范围外的字，WebView2 按需读取随包的完整黑体或宋体；离线即可显示原字库支持的生僻字。字体文件及维护要求见[离线字体规范](../docs/design/README.md#工作台离线字体)。安装包校验值与实测结果见[Windows 0.2.3 发布记录](../docs/windows-0.2.3-fonts.md)。

## 贴顶和内存

0.2.2 在侧栏贴顶收成感应条或原生窗口最小化连续 10 秒后，请求 WebView2 降低工作集。展开时立即请求恢复普通模式。贴顶时工作台暂停当下教学和出生参考日期的分钟轮询，返回后按缓存时间补取。胶囊仍按原有逻辑展示摘要。实测指标、适用条件与复现命令见 [WebView2 内存对照](../docs/webview-memory-2026-11-27.md)。

## 构建与验证

构建机需 x64 Windows、MSVC C++ 工具链、Windows SDK、Rust、Node 及根项目锁定的 pnpm。首次获取构建依赖需要联网。默认构建会从微软获取 WebView2 完整离线安装器，也可使用下文已核验的本地文件。用 PowerShell 7 在仓库根目录执行：

```powershell
./desktop/build.ps1
```

安装程序位于 `desktop/src-tauri/target/release/bundle/nsis`。CLI 版本由脚本指定，Rust 依赖见 `src-tauri/Cargo.lock`。发布目录只需分发安装程序和校验值。测试用的浏览器调试端口只在自动化验收进程环境中启用。

`verify-installed.cjs` 用于验证安装后的真实 WebView、10 个业务接口、断网事件后的出生对照与量表评分、收起和展开。验证机额外提供与仓库 Playwright 匹配的 `playwright-core`，以调试端点作为命令行参数。桌面程序正常启动无需这些测试工具。

在 Windows 验收机启用贴顶自动隐藏时，可执行 `node desktop/verify-installed.cjs <本机CDP端点> <本次启动的运气通进程PID>`。此模式需要 Python 3，会先展开该测试进程的窗口、核对原生尺寸，再验证工作台。测试完成后恢复光标。

### 使用已核验的 WebView2 离线安装器

构建机已有 Microsoft Evergreen Standalone Installer **x64** 时，可直接制成完整离线包。请从可信分发记录取得该文件的 SHA-256。保留仓库锁定的其余构建依赖，使用 PowerShell 7 执行以下命令。示例摘要来自本机已验证的 0.2.1 完整安装包所含的微软文件。

```powershell
./desktop/build.ps1 -OfflineWebView2Installer 'D:\YunQiBuilds\MicrosoftEdgeWebView2RuntimeInstallerX64.exe' -OfflineWebView2Sha256 '45769D66809A9652050F8A91AB5329881B65CC4123FE7C733841DEEFBEF91BF6'
```

脚本检查文件摘要、微软有效签名以及 Edge 安装程序的文件标识，并再次核对打包副本的摘要。运行此完整包时，安装器在 WebView2 缺失或已装版本低于 145 时使用内嵌载荷。`-UpgradeOnly` 用于已具备规定运行时的升级包，与上述两个本地载荷参数互斥。
