# Phase3-E Clinical Validation Kit

This is a controlled documentation kit for an expert review of the read-only
YunQi rule Workbench. It is not a patient-record repository, a clinical
decision system, or evidence of clinical efficacy.

## What the kit covers

- current YunQi structure;
- arbitrary-year YunQi structure; and
- specified-time YunQi structure from an explicit Beijing standard time.

The current E1 Workbench route is /yunqi/calculate. Its result is rule
calculation and presentation only. It does not create patients or inquiries,
collect symptoms, persist clinical data, or provide diagnosis, syndrome
differentiation, treatment, prescription, medication, risk, recommendation, or
AI capability.

## Contents

- protocol.md — 30–45 minute independent expert review protocol;
- reference-cases.template.csv — blank rule-reference input template;
- reference-case-selection-guide.md — coverage guidance without expected values;
- demo-feedback.template.md — de-identified session feedback form;
- gate-matrix.template.md — G1–G6 evidence gate form;
- sessions/ — empty until a real de-identified session is supplied;
- references/ — empty until a real expert reference source is supplied.
