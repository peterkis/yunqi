# Reference Case Selection Guide

This guide helps an expert assemble a future reference set. It does not
contain candidate expected values and does not authorize Codex to generate
them.

## Target size

The recommended final set contains 12–20 independently reviewed cases, with 18
as a useful target for broad first coverage.

## Coverage goals

The expert should consider:

1. at least two cases for each of the six Six-Qi stages;
2. at least six cases close to a stage boundary;
3. multiple YunQi years;
4. both Tai Guo and Bu Ji Sui Yun states;
5. different Si Tian and Zai Quan combinations;
6. ordinary mid-stage times and boundary-near times; and
7. times near the YunQi-year boundary when useful.

The final selection is an expert decision. A system-generated boundary
candidate is only a coverage aid and is never independent evidence that the
boundary rule is correct.

## Time selection safeguards

- Record every input as Beijing standard local time with explicit +08:00
  semantics.
- Preserve the supplied time exactly in the reference source.
- Do not replace a disputed time with a nearby convenient time.
- Do not derive an expected field from the system's actual response.
- If a date is disputed, retain the dispute and its basis rather than silently
  correcting the row.

## Review metadata

Every CONFIRMED row needs an actual reviewer, review date, expected values, and
source or basis. PENDING and DISPUTED rows are retained for traceability but
must not enter an automatic PASS baseline.
