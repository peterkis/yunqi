## 工作台离线字体

工作台沿用思源黑体与宋体的视觉分工。正文和控件使用 `--font-sans`，干支标题、古籍原文等使用 `--font-serif`。每个家族随包提供两份 400–700 可变字重的本地 WOFF2。

| 用途 | 黑体 | 宋体 |
| --- | --- | --- |
| 常用界面文字 | `YunQiUISans-VF.woff2`（304,892 B） | `YunQiUISerif-VF.woff2`（404,068 B） |
| 其余文字的离线回退 | `NotoSansSC-VF.woff2` | `NotoSerifSC-VF.woff2` |

- [字体样式](../../apps/yunqi-workbench/src/styles/fonts.css)在原有 CSS 家族名 `Noto Sans SC`、`Noto Serif SC` 下分别声明两个字体文件。每一家族的两组 `unicode-range` 互斥，合起来覆盖 U+0000–U+10FFFF。浏览器按实际文字和字体可用字形选择，其中“甲”命中常用字库，“龘”由对应的完整原字体绘制。各声明使用 `font-display: swap`、`font-weight: 400 700`。
- HTML 只预载常用黑体，页面出现宋体文字时加载常用宋体。当下页可用常用字“甲”提前加载环中央的宋体标题。空缓存浏览器进入当下、先天、量表默认页面，当前两份常用字库的字体资源正文合计 708,960 B。展现常用范围以外的文字时允许增加完整字库请求。所有字体、许可、图标均随应用离线分发，禁止远程字体或图标服务。网页部署若配置不可变缓存，更换字库内容时须同步更新字体 URL 及引用。
- 原始黑体、宋体和 SIL OFL 1.1 许可从上游同步，随[工作台字体资源](../../apps/yunqi-workbench/public/fonts)完整分发。派生字库使用自己的内部名称 YunQi UI Sans／YunQi UI Serif，并保留原版权及许可。更新上游文件时，同时核对上表原件摘要、两种字库的字重、字形和同家族回退。
- 当前两份常用字库各覆盖 1,119 个码点。调整文字范围时，审阅[字符表](../../apps/yunqi-workbench/scripts/ui-font-characters.txt)，按[生成脚本](../../apps/yunqi-workbench/scripts/build-ui-fonts.py)的依赖说明重新生成并检入两份常用字体与四条 CSS 声明。普通构建直接使用仓库内的产物。更新本表的大小和 [Workbench 验收](../agents/verification.md#ui验收门禁)，验证冷启动请求、实际字形、稀有字回退和换行。

## 独立侧栏窗口（宿主契约，2026-11-18 确认）

运气通作为**独立侧边栏程序**运行，不嵌入门诊医生站页面。Web 层按以下契约实现；浏览器执行结果另记于实施证据，真实窗口行为留待 Tauri 阶段验收：

| 项 | 约定 |
| --- | --- |
| 展开窗口 | 0.1.6 桌面浮窗宽 400，首选高度默认 1020、手调下限 680 逻辑像素。实际高度受当前显示器可用工作区限制。底边调高后记忆首选值，拖动标题记忆位置。 |
| 展开边界 | 面板即窗口，左缘用 1px `border-default` 细线表达边界；`shadow-dock` 只在浏览器开发宿主可见 |
| 停靠方式 | 允许贴顶时，将标题拖到当前工作区上沿附近松手可停靠。0.1.8 起，收到鼠标离开事件后计时，连续离开达到 350 ms 后收成 6 逻辑像素的绿色条，圆角外透出桌面。移回取消待执行的隐藏，悬停原位置展开。拖离顶部或使用托盘开关可解除。 |
| 置顶与恢复 | 0.1.7 起，启用图钉时记住浮动或贴顶状态和托盘偏好，暂停自动隐藏并置顶。取消置顶时恢复原状态；置顶期间实际拖动展开窗口后，取消置顶时保留新的浮动位置。重启沿用这一选择。 |
| 底部拖动条 | 拖动区透出与页脚连续的面板渐变。横线保留主题文字颜色和悬停反馈。 |
| 收起窗口 | 透明、无边框、置顶、不进任务栏。可见胶囊 400×64，收起态页面根、主题根和视口均透明。桌面与浏览器各自的宿主几何见下方“收起位置”。 |
| 收起阴影 | 不用系统原生窗口阴影（它沿矩形窗口绘制，会在 32px 圆角胶囊外露出直角）；阴影由 CSS `shadow-pill`（0 2px 8px）在透明窗口内绘制，3σ 尾迹完全落在外边距内 |
| 收起位置 | Windows 0.1.6 使用 424×78 的透明宿主，400×64 的可见胶囊顶部无留白、两侧各 12、下方 14。默认沿所在显示器水平中心对齐、贴工作区上沿。按显示器记忆手动位置，旧手动位置按可见胶囊锚点换算，失效时回到默认。网页模拟宿主保留 424×88。 |
| 透明边距 | 外边距区域会拦截极少量点击；边距已按阴影尾迹取最小值，不再扩大 |

## 出生信息直录（v2）

初始内嵌页采用淡墨山水、同心圆章、一行年月日及浅玉色键盘。标题与圆章使用项目思源宋体，控件使用思源黑体，输入数值和数字键沿用等宽字体。圆章直接消费当前日期预览的年度标签；仅有出生年时显示「待定」，农历多匹配时显示「待核对」，大寒交界涉及两个运气年时列出两项候选。只有归属唯一时才展示相应干支和岁运。修改和补全生日抽屉继续使用下划线字段与通栏键盘。

山水装饰随应用[本地打包](../../apps/yunqi-workbench/src/features/yunqi/birth/assets/misty-mountains.webp)，按明暗主题调整墨色，强制颜色模式隐藏装饰。圆章轮廓由 CSS 绘制，文字保留为可读的页面内容。

<details><summary>山水素材生成记录</summary>

内置 ImageGen 提示词：传统中国淡墨山水横幅底纹，用于运气通出生录入页。约 2.5:1 的横向构图，青灰单色写意水墨，纸上湿笔晕染，有远近两三层山脊。左下角有稍近的山坡，右侧稍高，群山从两侧向中央低伏，中央大面积留白给界面的圆章和文字。整体清浅静谧，山脚、上缘自然淡入透明。不画圆章、边框、文字、印款、建筑或人物。背景透明，只保留墨迹。

</details>

首次打开先天对照时，年龄格直接获得焦点。内嵌页的日期栏使用间点分隔三段输入，数字键盘位于画布底部，浅玉色只用于键帽，主操作独立显示在下方画布上。结果页的两个入口在底部抽屉复用同一表单。「修改」回填当前资料并全选已提交的公历出生年，方便直接覆盖；月日、历法与已知时刻一并回填。「补全生日」保留原录入方式，缺月时聚焦月份，已有月份时聚焦日期。抽屉只编辑草稿，Esc、关闭按钮或点击遮罩可放弃修改；新对照成功后替换原结果，清理原关联答卷。

年龄限 0–120 岁。年龄模式取服务端业务今日。只录年龄先以当前公历年减年龄；公历出生月晚于当前月时再减一，同月须在已填出生日晚于今天时才减一。只有月份也可按修正后的年份对照，字段下方标明按月或按日修正。例如以 2026-11-23 为基准，46 岁推算 1980 年，填 12 月或 11 月 24 日后修正为 1979 年，填 11 月 23 日仍为 1980 年。手填公历年时，农历月日仍只在所填公历年内换算。年龄搭配完整农历月日则查询有效范围内的两个可能公历年（当前年减年龄，以及前一年），用服务返回的公历生日与服务端业务今日核对实际周岁。未填完整农历月日时保持原有按年推算。

等宽数字优先使用本地 Lucida Console，保留等宽字体后备。键入、粘贴及屏幕数字键均在写入前校验；允许 01–09 的前导零组合。非法尝试保留原值，只有出错字段的标题和下划线变朱砂色，字段下方一行文字提示原因。标准动效下轻颤该字段，减少和关闭动效时通过文字和颜色反馈。改月后原日不合法，保留原日并暂停提交。

完整日期后误按一位数字时，若追加后越界，保留原值并用浅琥珀色提示范围及保留的日期。例如平年 2 月已填 3 日，再按 9，日栏仍为 3。预览核对通过后，可点击「确认并对照」或按 Enter 提交 2 月 3 日。

年份有效即可「仅按年份对照」，完整日期为「确认并对照」。完整日期的公历匹配和干支来自服务端，交界日才显示「补录时刻」。农历多匹配先核对对应公历日。按年龄填写完整农历月日时，须等待所有候选年份都换算成功，不使用单边结果；无同龄匹配时提示核对周岁及月日，多匹配（包括跨年或闰月）时须手动选择，不自动回退到单一年份。[出生录入契约](../contracts/YQ-API-CONTRACT-1.4.0.md)

## 本地扩展

- 出生录入的空格聚焦时只显示光标，失焦后恢复占位横杠。结果摘要的文字操作与摘要按基线对齐，悬停使用青玉文字和下划线。存在多项候选时，各卡首行左侧显示「可能出生区间」，右侧以胶囊显示服务端归属名称，首项用雾蓝灰、末项用浅玉色。候选区间的两个时间端点另起一行，窄屏按完整端点换行。
- 页头采用医小修的小尺寸透明标识，深色主题使用带细描边的版本。副标题为「测试版 · 待接入HIS」。
- 页头主题按钮使用本地 Lucide 月亮与太阳图标。标准动效下，鼠标悬停时图标轻旋并放大，切换主题时播放切换反馈；精简与关闭动效时保留颜色反馈。
- 当下运气、其下钻页及先天对照的按下反馈沿用青玉配色，文字操作保留透明底，主操作用深青色。
- `DateField`：年/月/日三段数字输入，`label` 必填并作为可见legend和整体可访问名称，完整公历日期类控件使用统一 `--input-height` 与焦点环；
  支持满位跳格、空段退格和完整日期粘贴，各段有年/月/日可访问名称。
  对外为 `YYYY-MM-DD` 或空；只校验位数与年1900–2100、月1–12、日1–31，月份天数交给API。
  出生时刻保留 `type="time"`，统一令牌外观，业务时区仍为北京时间 UTC+08。
- `SegmentedControl`：非路由的按钮分段，用于量表性别、出生年份录入方式和月日历法。
  采用radiogroup/radio与aria-checked、单Tab入口、方向键和Home/End；
  默认 `--segment-height`，compact为30px，与 `SegmentedNav` compact视觉一致；不替换路由导航或原文范围控件。
- 量表入口并列两张整卡可选的「男性量表」「女性量表」，以青玉与浅琥珀圆形符号区分，圆底色按 40% 不透明度叠在卡面上，图标保持清晰。卡片标题与节气环干支、先天圆章共用思源宋体（`--font-serif`），字号 20px，字重 500。选卡页的会话提示紧随选卡，三条说明位于滚动内容底部。结果页直接以可展开的说明收尾。点击卡片直接进入第一题。说明行与当下页「其余阶段」「年度详情」共用 44px 行高、14px 思源黑体和主题青玉色，右侧箭头随折叠状态转向。尚未填写先天资料时，候选区间显示空态说明。
- 量表结果卡右上角可展开「判定标准」核对转化公式及阈值。进入结果时焦点落在判定标题供读屏播报，标题无焦点描边；键盘切至「判定标准」等控件时显示焦点环。倾向标签在标题行靠右成组；窄窗内的单个倾向可与达标项数上下对齐，多标签换行时仍靠右。兼夹标签按转化分降序展示整数分，并列最高分用同一深朱砂色。九质分数条按未取整分值降序，右侧保留一位小数，同分时达标偏颇质优先。互参区按体质、先天、当下分三行；「先天」标签与整组候选垂直居中。跨大寒的两个候选以暖琥珀微标和交节前、交节起区分。

### 青玉环境光背景

Jade Ambient Surface 是展开态工作台共用的本地表面样式。授权范围是面板背景与内容卡片的低阴影处理，
这两项优先于上游关于渐变和卡片阴影的默认约定。实现和浅、深主题令牌见
[background-surface.css](../../apps/yunqi-workbench/src/styles/background-surface.css)。

- 在承载页面的工作台容器上使用 `.jade-surface`。容器底色上叠三处静态椭圆光晕，渐变在边缘衰减。
  只有内部内容区滚动，背景随视口尺寸适配。收起态只显示现有胶囊，宿主继续透明。
- 工作台已有信息、对照、量表和原文内容卡片自动使用同一表面。新增的一般内容卡可在该容器下使用
  `.jade-card` 复用底色、圆角与阴影。输入、选项、内部分隔线和焦点态仍由原组件负责。
- 渐变无法绘制时以纯色画布承接。高对比偏好关闭光晕与卡片阴影、恢复卡片边界，
  强制颜色模式使用系统背景与边界色。

先天原文线索按每个出生候选分别展示年度与阶段两张摘录卡。浅色五行洗色仅覆盖卡片左侧 20%，
正文其余区域使用卡片底色。深色沿用主题卡面，高对比模式回到纯色。标签和来源取自对应篇节，
年度岁运摘录按岁运元素配色，司天和阶段摘录按司天元素配色。按钮与折叠入口的标题禁止鼠标选字，经文和出处可选择复制。
摘录卡的渐变从边框外沿一次绘制到底，避免透明边框处露出白线。先天对照卡的关系解读按钮高 36px，上方与时刻信息相距 14px。

### 当下关系解读与原文

展开「这些关系怎么读？」后，先读年度关系，再读当前气步关系。范围标签与标题分开排版，

### 工作台滚轮手感

主内容区或原文阅读区向下滚动 240px 后，页脚右端显示「返回顶部」文字，悬停或键盘聚焦时加下划线。激活后，焦点回到该滚动区。
用户主动点击「返回顶部」或按 Enter 时，应用用 `requestAnimationFrame` 逐帧回滚。标准档约 320ms。自动档遇到系统减少动效（如 Windows 关闭窗口动画）或性能降档时，仍使用约 240ms 的短缓动。手动选择「精简」或「关闭」，以及应用强制关闭动效时，直接回顶。滚轮、触控或键盘输入可中断回滚。缺少逐帧动画能力时使用原生 CSS 平滑滚动，浏览器可降级为即时回顶。页脚左侧将部门与「联合研发」紧凑成组，版权标为 © 2026-2027。

完整动效模式按需加载 [Lenis 1.3.27](https://github.com/darkroomengineering/lenis/blob/v1.3.27/README.md)，
通过原生滚动容器更新位置。正文和两处原文阅读区一次只有指针所在区域处理滚轮。
粗粒度滚轮采用 `lerp=0.28` 的指数阻尼与 `wheelMultiplier=0.9`，连续输入的待滚距离最多为可视区高度的 55%。
反向滚动从当前可见位置重新起步。触屏和小于 32px 的细粒度像素输入使用系统滚动。
收起、切页、切到后台、键盘操作或指针按下时结束余程。自动档跟随系统的减少动效偏好与设备降档结果；
精简和关闭档使用原生滚动。用户在「动效设置」手动选择「标准」后，即使系统偏好减少动效，运气通也启用标准滚轮手感。
强制颜色模式及 `?motion=off` 仍优先关闭动效。
