# 运气通 UI 设计规范与原型

2026-11-17 起，Workbench 进入 UI 界面重构。本目录是界面视觉与交互的唯一依据；
重构前 `apps/yunqi-workbench` 的页面布局、样式和交互形态均为 demo，不再作为设计参考，
也不作为新界面的验收基线。

设计规范不改变规则、API Contract、固定北京时间语义或医疗边界；这些仍以
[AGENTS.md](../../AGENTS.md) 及 [docs/agents](../agents/README.md) 为准。两者冲突时，
先按现有授权与边界执行，并把冲突记录到重构计划中等待用户决定。

## 独立侧栏窗口（宿主契约，2026-11-18 确认）

运气通作为**独立侧边栏程序**运行，不嵌入门诊医生站页面。Web 层按以下契约实现；浏览器执行结果另记于实施证据，真实窗口行为留待 Tauri 阶段验收：

| 项 | 约定 |
| --- | --- |
| 展开窗口 | 宽 `panel-width` 400，高为当前显示器工作区高度（扣除任务栏），贴屏幕右缘；无系统标题栏与边框 |
| 展开边界 | 面板即窗口，左缘用 1px `border-default` 细线表达边界；`shadow-dock` 只在浏览器开发宿主可见 |
| 停靠方式 | 默认在 Windows 上注册为 AppBar，预留右侧 400px，最大化的门诊工作站自动让出宽度而不被遮挡；设置中提供“悬浮覆盖”开关（置顶、不占位） |
| 收起窗口 | 透明、无边框、置顶、不进任务栏；尺寸 `pill-window-width` × `pill-window-height` = 424×88，胶囊 400×64 水平居中，外边距左右 12、上 10、下 14；收起态 `html`、`body`、主题根与视口底色均透明（含开发宿主） |
| 收起阴影 | 不用系统原生窗口阴影（它沿矩形窗口绘制，会在 32px 圆角胶囊外露出直角）；阴影由 CSS `shadow-pill`（0 2px 8px）在透明窗口内绘制，3σ 尾迹完全落在外边距内 |
| 收起位置 | 默认工作区右上角；可拖动，记住上次位置（按显示器分别记忆）；位置越界时回到默认 |
| 透明边距 | 外边距区域会拦截极少量点击；边距已按阴影尾迹取最小值，不再扩大 |

## 本地扩展

- `DateField`：年/月/日三段数字输入，`label` 必填并作为可见legend和整体可访问名称，出生页传“出生日期（公历）”；统一 `--input-height` 与焦点环；
  支持满位跳格、空段退格和完整日期粘贴，各段有年/月/日可访问名称。
  对外为 `YYYY-MM-DD` 或空；只校验位数与年1900–2100、月1–12、日1–31，月份天数交给API。
  出生时刻保留 `type="time"`，统一令牌外观，业务时区仍为北京时间 UTC+08。
- `SegmentedControl`：非路由的按钮分段，用于量表性别和出生时刻是否已知。
  采用radiogroup/radio与aria-checked、单Tab入口、方向键和Home/End；
  默认 `--segment-height`，compact为30px，与 `SegmentedNav` compact视觉一致；不替换路由导航或原文范围控件。
- 量表作答时性别收为眉标；有答案的更换操作在页内确认清空题数，支持取消与Esc及焦点恢复。
  本地扩展样式位于Workbench的 `styles/views/form-controls.css`、`birth.css`、`constitution.css`，不改同步副本。

### 青玉环境光背景

Jade Ambient Surface 是展开态工作台共用的本地表面样式。授权范围是面板背景与内容卡片的低阴影处理，
这两项优先于上游关于渐变和卡片阴影的默认约定。实现和浅、深主题令牌见
[background-surface.css](../../apps/yunqi-workbench/src/styles/background-surface.css)。

- 在承载页面的工作台容器上使用 `.jade-surface`。容器底色上叠三处静态椭圆光晕，渐变在边缘衰减。
  只有内部内容区滚动，背景随视口尺寸适配。收起态只显示现有胶囊，宿主继续透明。
- 工作台已有信息、对照、量表和原文内容卡片自动使用同一表面。新增的一般内容卡可在该容器下使用
  `.jade-card` 复用底色、圆角与阴影。输入、选项、内部分隔线和焦点态仍由原组件负责。
- 渐变无法绘制时以纯色画布承接。高对比偏好关闭光晕与卡片阴影、恢复卡片边界，
  强制颜色模式使用系统背景与边界色。

先天原文线索按每个出生候选分别展示年度与阶段两张摘录卡。浅色五行洗色仅覆盖卡片左侧 20%，
正文其余区域使用卡片底色。深色沿用主题卡面，高对比模式回到纯色。标签和来源取自对应篇节，
年度岁运摘录按岁运元素配色，司天和阶段摘录按司天元素配色。按钮与折叠入口的标题禁止鼠标选字，经文和出处可选择复制。

### 当下关系解读与原文

展开「这些关系怎么读？」后，先读年度关系，再读当前气步关系。范围标签与标题分开排版，
右侧徽章复用主卡的关系色映射（相合蓝、相违琥珀、中性灰）；「相生 · 相得」在解读卡上简记为「相得」。
未知标签保留接口原词与中性色。推演口径置于两卡下方，沿用 API 返回的当步运说明。

| 视觉角色 | 令牌与行为 |
| --- | --- |
| 解读子卡、维度标签 | `reading-insight-surface`、`reading-scope-surface`，正文和次要信息沿用墨色阶梯 |
| 出处胶囊 | `reading-source-surface` 配 `accent` 前景，长题名可换行；内网版显示可复制的短书目，悬停可读完整题名，不提供外链或外链图标 |
| 原文卡和标签 | 当下原文复用先天摘录的 `reading-excerpt` 表面，默认雾青；五行洗色与圆点由 `excerpt-{wood,metal,water,fire,earth}-{wash,pigment}` 供应，渐变在左侧 20% 衰减 |
| 画布脚注 | 当下页面有摘录时，在联合研发署名上方固定展示「◆ 文献线索，非个体发病预测」，切换页面时由当前视图释放 |

折叠以原生 `details/summary` 支持点击、Enter 和空格。标准动效且浏览器支持内在高度插值、
离散过渡和 `::details-content` 时启用高度与透明度过渡。精简、关闭及不支持这些特性的环境直接开合。
没有渐变或混色支持时仍有纯色卡面、标签底色与文字。高对比偏好移除摘录渐变，强制颜色模式下出处书目使用系统文字色。

当下双栏的倒计时使用 `countdown-bg`、`countdown-fg` 与 11px 的 `ts-countdown`。浅琥珀只表示时间提醒。年度阶段选择用 `accent-subtle`、`accent-muted` 配合单选标记。
工作台直接显示 API 的本地时间，界面和读屏文案省略默认时区。先天对照的「所处运」在各侧并排列出主客五音，「所处气」保留双行。
「所处运」的一对五音用间隔号分开，例如「主 太羽 · 客 少商」。
这两行的阶段标题按左右各自的客方取色。「所处气」使用该侧的 `currentStep.guestQi`，「所处运」使用 `currentMovement.guest.element`。
标题使用独立的 `element-{wood,fire,earth,metal,water}-title` 令牌，浅深主题均要求与卡面对比度至少为 4.5∶1。圆点沿用五行点色并靠近中轴，金为空心环，其余为实心点。未知五行使用普通标题文字。
「当下运气 → 其余阶段 → 六步交接时间线」的每个气步标题也使用这套标题色和圆点，取值来自该步的客气。已结束、当前、未开始由标题旁的状态文字单独表示。
从「同时测评体质」进入体质量表标签页后，使用该次出生对照的快照；切换标签保留进度，重新提交或清空出生资料会销毁关联答卷。

### 工作台滚轮手感

完整动效模式按需加载 [Lenis 1.3.27](https://github.com/darkroomengineering/lenis/blob/v1.3.27/README.md)，
通过原生滚动容器更新位置。正文和两处原文阅读区一次只有指针所在区域处理滚轮。
粗粒度滚轮采用 `lerp=0.28` 的指数阻尼与 `wheelMultiplier=0.9`，连续输入的待滚距离最多为可视区高度的 55%。
反向滚动从当前可见位置重新起步。触屏和小于 32px 的细粒度像素输入使用系统滚动。
收起、切页、切到后台、键盘操作或指针按下时结束余程。自动档跟随系统的减少动效偏好与设备降档结果；
精简和关闭档使用原生滚动。用户在「动效设置」手动选择「标准」后，即使系统偏好减少动效，运气通也启用标准滚轮手感。
强制颜色模式及 `?motion=off` 仍优先关闭动效。
