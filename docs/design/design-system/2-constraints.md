# 统一约束

做任何新界面前对照这张清单。每一条都是硬约束。

## 视觉

- 只用本系统的令牌，不写裸色值、裸字号、裸间距。
- 字体只从本地 `fonts/` 加载；任何页面、预览、导出物都不得引用 Google Fonts 等外网资源（院内网无外网）。图标同理，内联 SVG，不用在线图标库。
- 一屏最多 5 级字号；`display-*` 每张卡最多一个。
- 黛青只用于：品牌标、当前态、主按钮、链接、焦点、进度当前段。每个视图最多一个黛青实底按钮。
- 关系色只出现在关系标签和对应条形里；五行色只出现在圆点里。
- 卡片不加阴影；阴影只给选中分段、停靠面板、胶囊条与弹层。
- 不用渐变（进度条当前段的“已走过部分”除外，以硬边分割表示）、不用插画、不用 emoji、不用左侧粗色条卡片。
- 图标：1.8–2px 线性描边、圆端点，16 或 18px，颜色继承文字。仅用于窗口控制和导航箭头，不给内容配图标。

## 交互

- 默认视图不需要滚动就能看到全年 + 此刻两张卡（工作站高度 ≥ 900）。
- 展开内容用：下钻（原文、结果）、`details` 折叠（“这些关系怎么读？”“展开全段”）。不用弹窗，不用悬停才出现的信息。
- 量表一题一屏，选中后 160ms 自动进入下一题；数字键 1–5 作答；随时可返回上一题。
- 患者切换由 HIS 驱动；出生日期默认取 HIS，可手动改。修改、清空或结束测评会销毁本次答卷。
- 点击面积 ≥ 32×32（图标按钮），量表选项与主按钮 ≥ 40 高。

## 文案

- 术语保留原貌（司天、在泉、客主加临、太羽、少商），首次出现时在旁边给一句白话。
- 关系标签用传统术语；说明句用“谁 + 动词 + 谁”的结构：“中运水 克 司天火”“客金生主水”。
- 时间一律写“北京时间 UTC+08”，节气用“→”连接区间。
- 患者姓名中间字脱敏（张*林）。
- 声明性文字放页脚或卡片末尾，用 `meta` 样式，一句话说完，不用感叹号。

## 医疗安全（设计层面的约束）

- 不出现“易患”“风险”“预测”“高危”等措辞，也不用红色、警示图标、仪表盘、风险条等暗示风险分级的视觉形式。
- 原典病候必须带出处，并与“文献线索，非个体发病预测”的说明同屏出现。
- 体质结果、先天运气、当下运气以**并列事实**呈现，不画箭头连成因果，不生成“综合结论”。
- 五步运交运日期属“教学口径、待专家确认”，在页脚标明。

## 可访问性

- 正文对比度 ≥ 4.5:1，两套主题都已核算；`ink-tertiary` 是可读文字的下限。
- 区分靠明度 + 文字，不只靠色相。
- 所有可点元素是真实的 `button` / `a` / `input`；图标按钮带 `aria-label`；进度条、时间条带 `role="img"` 与完整的 `aria-label`。
- 焦点环：2px `focus-ring`，偏移 2px，所有可聚焦元素可见。
