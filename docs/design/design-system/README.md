# 运气通 YunQi 设计规范

运气通是中医科门诊医生工作站旁的一个**侧栏插件**：医生接诊时，它贴在屏幕右缘，用一屏告诉医生“今年的运气是什么、此刻处在哪一段、患者出生时是什么”，需要时再展开原文、对照和体质量表。

这份规范约束它的全部界面。一句话概括风格：**简洁、克制、像一本排得很好的小册子**——层次靠字体、字重、留白和细线建立，而不是靠颜色、阴影和图标堆出来。

## 设计原则

1. **不打扰主流程。** 插件永远是配角。固定宽 400px，停靠右缘，可收成 64px 胶囊条；不弹窗、不抢焦点、不发声音。病历区始终完整可用。
2. **一屏只说最重要的事。** 默认视图只有两张卡：全年（干支、岁运、司天、在泉）和此刻（当步气、当步运）。其余阶段、原文、对照、量表都“按需展开”，不预先铺满。
3. **结论旁边永远有解释。** 每个关系标签（顺、逆、不和、相得……）后面紧跟一句白话，让不熟悉理论的医生也能读懂。
4. **原文与解读分开。** 古籍原文用宋体，现代释义用黑体，出处单独一行。读者一眼就知道哪句是经典、哪句是解读。
5. **只呈现，不诊断。** 原典病候是文献线索，不改写为患者的发病预测；系统不自动辨证、不给方药。这条同时是设计约束：界面上不出现“风险等级”“易患疾病”之类的视觉语言。

## 色彩

整体是**暖白底 + 墨色文字 + 一个黛青色**。其余颜色都有固定语义，不能拿来装饰。

| 角色 | 令牌 | 浅色 | 用在哪里 |
| --- | --- | --- | --- |
| 底 | `surface-page` | #FBFAF7 | 面板底、页脚、内嵌提示块 |
| 承载面 | `surface-card` | #FFFFFF | 卡片、输入、选项 |
| 凹陷面 | `surface-sunken` | #EFEDE7 | 分段轨道、中性标签、悬停 |
| 主文字 | `ink-primary` | #1D2320 | 标题、干支、关键值 |
| 次文字 | `ink-secondary` | #4A524E | 正文、解释句 |
| 弱文字 | `ink-tertiary` | #5F6662 | 标签、出处、时间——**最浅的可读文字** |
| 品牌 | `accent` 黛青 | #2E5B4F | 主按钮、当前态、链接、焦点 |

**关系色只有两组**，按“相合 / 相违”二分，而不是按每个术语一种颜色：

- 相合（顺、从、相得、顺化、相生）→ 蓝：`relation-favorable-bg` / `-fg`
- 相违（逆、不和、天刑、小逆、相克）→ 橙棕：`relation-adverse-bg` / `-fg`
- 中性（同五行、天符、同属）→ 灰：`relation-neutral-*`

蓝与橙在色相和明度上都拉开，色弱医生也能分辨；而且标签里**永远写字**，颜色只是第二线索。不用红色——红会被读成“报警”，而运气关系不是病情严重度。

**五行圆点**：木 `element-wood`、火 `element-fire`、土 `element-earth`、金（空心环 `element-metal-fill` + `element-metal-ring`）、水 `element-water`。只作 7–8px 的识别点，旁边必须跟五行名称；不得放大成色块，也不得给文字上五行色。

**比例**：一屏之中，黛青面积不超过 5%（通常只有品牌标、当前分段的文字、一个主按钮）；关系色只出现在标签里；其余全是底色和墨色。

深色主题已定义（`dark`），所有文字对比度经过核算：浅色最低 5.0:1，深色最低 5.1:1。

## 字体

两个家族，分工明确：

- **宋体 `serif`（Noto Serif SC）**：干支、阶段名、结论名词、题干、古籍原文。它负责“有分量的东西”和“经典的声音”。
- **黑体 `sans`（Noto Sans SC）**：其余一切——数值、说明、标签、按钮、表单。

### 本地加载（强制）

院内网无法访问外网，**字体一律随应用下载、本地加载，禁止引用 Google Fonts 或任何在线字体服务。** 字体文件就在本系统的 `fonts/` 目录：

| 文件 | 家族 | 字重 | 大小 |
| --- | --- | --- | --- |
| `fonts/NotoSansSC-VF.woff2` | Noto Sans SC（思源黑体） | 400–700 可变 | 约 7.7 MB |
| `fonts/NotoSerifSC-VF.woff2` | Noto Serif SC（思源宋体） | 400–700 可变 | 约 11 MB |
| `fonts/OFL.txt` | SIL Open Font License 1.1 | — | 允许随软件分发 |

- 来源：Google Fonts 官方仓库（google/fonts）的可变字体，转为 woff2，字重轴裁到 400–700（本系统只用 400/500/600/700）。
- **未做字符子集化**：完整保留简体字库，古籍原文中的生僻字（迺、霿、胕、脽、欬、瘅、鼽、衄等）均已核对可显示。不要为了减小体积再做子集，否则原文会出现豆腐块。
- 一个可变字体文件覆盖全部字重，不需要分别加载 regular / medium / bold。

部署方式：

1. 把 `fonts/` 目录原样放进插件的静态资源（Tauri 宿主打包进应用资源；或放到内网 Nginx 静态目录，同源访问）。
2. 用 `@font-face` 声明，`font-display: swap`，字重写成范围：

```css
@font-face {
  font-family: "Noto Sans SC";
  src: url("./fonts/NotoSansSC-VF.woff2") format("woff2");
  font-weight: 400 700;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Noto Serif SC";
  src: url("./fonts/NotoSerifSC-VF.woff2") format("woff2");
  font-weight: 400 700;
  font-style: normal;
  font-display: swap;
}
```

3. 首屏只预加载黑体：`<link rel="preload" href="./fonts/NotoSansSC-VF.woff2" as="font" type="font/woff2" crossorigin>`。宋体按需加载。
4. Nginx 部署时给 `.woff2` 设 `Cache-Control: public, max-age=31536000, immutable`，文件名变更即换版本。
5. 字体加载完成前的回退：黑体 → 微软雅黑（Windows 工作站）→ 苹方；宋体 → SimSun → 宋体-简。回退字形宽度相近，不会造成布局跳动。

本系统的 `tokens.json` 已在 `type.fonts` 中登记这两个文件，生成的 `tokens.css` 会自动带上对应的 `@font-face`。

### 在 Design 画布上使用

原型画布安装本系统后，每个画板在 `support.js` 之后加载 `ds/yunqi/tokens.css`，颜色、间距、圆角、阴影一律写成 `var(--令牌名)`，字体写 `var(--font-sans)` / `var(--font-serif)`。字体随 `ds/yunqi/fonts/` 一并复制到画布，不走外网。

## 字号与排版

字号阶梯共 15 级，但**单屏最多出现 5 级**。

| 层级 | 样式 | 规格 | 示例 |
| --- | --- | --- | --- |
| 第一眼 | `display-xl` 宋 | 40 / 1.0 / 700，字距 0.04em | 丙午 |
| 结论 | `display-lg` 宋 | 30 / 1.1 / 700 | 气虚质 |
| 列头 | `display-md` 宋 | 24 / 1.2 / 700 | 庚申 |
| 阶段 | `title` 宋 | 20 / 1.4 / 600 | 五之气 |
| 题干 | `question` 宋 | 19 / 1.55 / 600 | 您容易气短吗？ |
| 原文 | `quote` 宋 | 15 / 1.85 / 500 | 五之气，畏火临…… |
| 值 | `value` 黑 | 16 / 1.4 / 600 | 少阴君火 |
| 强调正文 | `body-strong` 黑 | 14 / 1.5 / 600 | 阳明燥金 |
| 正文 | `body` 黑 | 14 / 1.6 / 400 | |
| 说明 | `body-sm` 黑 | 12.5 / 1.65 / 400 | 客火克主金，客胜主为从 |
| 注释 | `caption` 黑 | 12 / 1.5 / 400 | 秋分 → 小雪 |
| 标签文字 | `chip` 黑 | 12 / 1 / 600 | 从 · 顺 |
| 眉标 | `label` 黑 | 11 / 1.4，字距 0.08em | 全年 · 2026 |
| 元信息 | `meta` 黑 | 11 / 1.4 | 《素问·六元正纪大论》 |
| 刻度 | `micro` 黑 | 10.5 / 1.2 | 初 二 三 |

排版规则：

- **眉标在上，内容在下。** 每个区块以 `label` 开头（ink-tertiary），说明“这是什么”，下面才是大字。眉标用“ · ”分隔多个信息。
- **数字与干支同排时**，干支用宋体大字，年份用黑体 13px 跟在后面，基线对齐。
- **原文用中文引号“ ”包起来**，省略用“……”，出处另起一行，用书名号《》。
- 行长：说明文字在 400 面板里自然约 26 个汉字一行，不要再加宽内容区。
- 不使用斜体、下划线（链接除外悬停时）、全大写。强调只用字重 600。
- 一律左对齐；只有完成态、空状态居中。
