# InfoCard
信息卡：插件里承载内容的唯一容器，全年、此刻、原文、对照、结果都是它。

- `surface-card` 底，1px `border-default`，`radius-lg` 14，内距 18（紧凑 16），**无阴影**。卡与卡间距 12。
- 结构固定：眉标行（`label` 左 + `meta` 右）→ 第一眼（一个 `display-*` 或 `title`）→ 内容 → 可选的下沉提示块。
- 小节之间用 1px `border-subtle` 分隔，线上下各 14。
- 下沉提示块：`surface-page` 底、`radius-md`、内距 10×12、无边框，放关系标签 + 说明或声明句。
- 整卡可点时（如原文入口）用 `a` 包裹，右上放“原文与释义 ›”文字链接，不加悬停阴影。
