# QuoteBlock
原文块：古籍原文、现代释义、出处三段分开排，读者一眼分清“经典说的”和“我们解读的”。

- 原文：`quote` 宋体 15/1.85/500，`ink-primary`。卡片内摘句用 `quote-sm` 13.5。
- 释义：上方 1px **虚线** `border-default` 隔开，眉标“阅读释义”，正文 `body-sm` `ink-secondary`。虚线是原文与解读的固定分界符号，别处不用虚线。
- 出处：`meta`，书名号《》，另起一行放最后。
- 长段落先显示节选（“……”），用 `details` “展开全段”。
- 病候原文不改写、不加粗、不高亮。
