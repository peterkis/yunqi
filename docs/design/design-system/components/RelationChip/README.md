# RelationChip
关系标签：把运气中的一种关系（顺、逆、不和、相得、天符……）压缩成一个带底色的胶囊，后面必须跟一句白话解释。

- 三种语气：相合 `relation-favorable-*`、相违 `relation-adverse-*`、中性 `relation-neutral-*`。按关系的性质归类，而不是一个术语一种颜色。
- 高 22px（对照表内 20px），左右内距 8，`radius-full`，文字样式 `chip`（12/600）。
- 文字用传统术语；两个术语并列时用“ · ”连接，如“从 · 顺”。
- 后接说明句：`body-sm`，`ink-secondary`，间距 8，例如“客火克主金，客胜主为从”。
- 禁止：只放颜色不放字；用红色；给标签加图标；在一行里放超过一个标签再接说明。
