## P0 · 一眼可见的瑕疵（先做）

### 1. 时间精度过高，主视图出现毫秒

现象：
- “此刻”卡第二行是 `2026-11-17 21:42:26.152`。
- 先天页“当下快照”、量表上下文条也带毫秒。
- 全年卡右上是 `交运 2026-01-20 09:44:56`，阶段区间精确到秒。

医生扫一眼读不出意义，反而像调试输出。

改法：
- 主视图一律用 `YunQiTimeDisplay variant="compact"`（`MM-DD HH:mm`），或只显示日期。
- 删除“此刻”卡第二行完整时间戳，眉标的“此刻 · 11月17日”已经够用。
- 阶段副标题改为 **“秋分 → 小雪 · 还有 5 天”**：
  - 节气名按步序静态映射：初 大寒→春分、二 春分→小满、三 小满→大暑、四 大暑→秋分、五 秋分→小雪、终 小雪→大寒。
  - 剩余天数在 mapper 内由 `dto.input.localTime` 与 `step.end.localTime` 计算，不读本机时钟，符合时间纯度门禁。
- 精确到秒的边界时刻保留在 `<time dateTime>` 里，并完整列在“计算说明与版本”中。

位置：`components/time/YunQiTimeDisplay.tsx`、`presentation/map-drilldown.ts`（`boundaryMeta`）、`CurrentYunQiParts.tsx`、量表 `ConstitutionContext.tsx`、先天页快照行。

验收：主视图任何位置不出现秒和毫秒；“计算说明与版本”展开后能看到精确时刻。

### 2. 体质结果的判定标题会溢出

现象：多个偏颇质判为“是”时，30px 宋体标题串成“气虚质、阳虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质”，折成三行，第一眼失效；下一行“兼夹”又把同一串重复一遍。

改法：
- 第一眼只放一个：转化分最高的“是”（平和质判定成立时就放平和质）。同分按标准附录顺序取第一个。
- 下方一行“兼夹”用中性 RelationChip 依次列出其余“是”，“倾向”另起一行列出。
- 不再重复整串文字。

验收：无论命中几种，标题都只占一行。

### 3. 先天对照提交后，表单仍完整展开

现象：提交后，日期框、复选框、两段说明、主按钮、候选区间说明、当下快照依次排在对照表前面，对照表被推到首屏之外。

改法：
- 提交后，表单折叠成一行摘要条：`1980-03-12 · 时刻不详 · 修改`。点“修改”再展开。
- 候选区间说明压成一行 meta：只有一个归属时写“当日无交界 · 归属唯一”；出现多个候选时才展开说明。
- “当下快照”不再单独占行，并入对照表“当下 · 今日”列头。

验收：在 1366×768 的工作站上，提交后首屏能看到对照表的列头和岁运行。

### 4. 原生表单控件破坏统一感

现象：
- 日期框显示 `mm/dd/yyyy`，格式随系统语言变化，还带原生日历图标。
- 复选框、单选框、年度下拉都是浏览器默认样式。
- 年度页默认“选择年份”空态，需要多点一次。

改法：
- **出生日期**：改为年 / 月 / 日三段数字输入（`inputmode="numeric"`，自动跳格），或单个文本框加 `YYYY-MM-DD` 掩码。保留 1900–2100 校验。
- **性别**：改用 SegmentedNav 的 30px 变体（男 / 女），与原文页的“全年 / 当下阶段”同一套组件。
- **“知道出生时刻”**：改成开关或分段控件“时刻不详 / 已知时刻”。成本最低的做法是全局加 `accent-color: var(--accent)`。
- **年度页**：默认选中当前运气年；下拉框统一 36px 高、`radius-sm`、自定义箭头。

### 5. 量表作答中仍常驻性别选择

现象：开始作答后，性别单选和说明一直占着第一屏。结果页上还出现一个错位的“返回修改 体质测评结果”行，既不像下钻标题，也不像按钮。

改法：
- 作答开始后，性别折叠为眉标“男性版 · 更换”。点“更换”先确认，确认后才清空答卷。
- 结果页去掉这一行：“返回修改”作为文字按钮放进底部操作区，页面标题交给 PanelHeader 的下钻样式。

## P1 · 层次与一致性

### 6. “这些关系怎么读？”展开后排版过重

现象：
- 带下划线的蓝色长链接，后缀“（新窗口）”，加项目符号列表。
- “教学口径，待专家确认”在同一块里出现两次，页脚又出现一次。

改法：
- 出处改为 `meta` 灰字书名号，整行可点；用 12px 外链图标代替“（新窗口）”文字，`aria-label` 里保留“新窗口打开”。
- 去掉项目符号。
- 删除重复的口径声明，交给页脚。

### 7. 当步运缺少关系标签

现象：当步气有“顺 · 客胜主”标签，当步运没有，两段节奏不对称。

原因：API 的 `currentMovement` 没有关系字段。前端不应自行推算生克（违反“业务结果来自 DTO”的分层）。

建议：在 domain 层为 `currentMovement` 增加 `relation`，结构与 `sixQi.steps[].relation` 一致，例如本例的“客生主，相得”。随契约小版本发布后，UI 直接复用 RelationChip。在此之前保持现状。

### 8. 主操作不在操作区

规范要求每个视图只有一个主按钮，且放在底部操作区。现在：

| 页面 | 现状 | 改为 |
| --- | --- | --- |
| 先天 · 未提交 | 主按钮在表单内 | 操作区主按钮“查看对照” |
| 先天 · 已提交 | “同时测评体质”是次按钮，在内容流中 | 操作区主按钮“同时测评体质” |
| 量表 · 作答中 | “结束并销毁答卷”整宽在内容流中 | 操作区左侧次按钮 |
| 量表 · 结果 | 同上 | 左“结束并销毁答卷”（次）+ 右“返回修改”（文字按钮） |

### 9. 当下页底部入口样式不一

现象：“年度详情 › 指定时点 ›”是一行文字链，下面两个 `details` 又是三角展开，三种入口三种样式。

改法：合并成一组“更多”列表，放在卡片之外：
- 行高 44，左侧文字，右侧 chevron，行间用 `border-subtle` 分隔。
- 依次为：其余阶段、年度详情、指定时点、计算说明与版本。

### 10. 原文页对齐与孤立声明

现象：
- 卡片左右边缘比上方分段轨道各内缩约 4px。
- “文献线索，非个体发病预测”孤零零浮在页脚上方。

改法：
- 卡片统一用面板 16px 安全边距。
- 声明并入卡片末尾的下沉提示块，与当下页原文卡的做法一致。
- “查看原文出处”去掉下划线，与“原文与释义 ›”用同一种文字链：常态无下划线，悬停才显示。

### 11. 收起态胶囊

现象：
- “丙午”是裸文字，缺少原型里 44px 黛青圆底的品牌识别。
- 在 400 宽窗口中胶囊贴边，阴影被裁掉。

改法：
- 加上圆标（`accent` 底、`accent-on` 字、宋体）。
- 胶囊外留 8px 边距。

## P2 · 工艺细节（达到“出版级”的最后一步）

12. **等宽数字**：日期、时间、年份、分数、进度“4/26”全部使用 `font-variant-numeric: tabular-nums`，目前只有部分地方生效。建议在全局给 `time`、`.num` 加上。
13. **进度条段内进度**：当前段现在整段实色，看不出这一段走了多少。改为硬边分割“已过 / 未过”（规范允许，不用渐变），比例由 mapper 计算。
14. **动效**：分段切换、选项选中、展开收起加 120–160ms `ease-out` 过渡；增加 `@media (prefers-reduced-motion: reduce)`，此时一律取消过渡。
15. **中文标点**：
    - 原文以全角引号“开头，首行视觉上像缩进。可以加 `text-spacing-trim: trim-start`（Chromium 支持），或者去掉外层引号（宋体加眉标已足以表明是原文）。
    - 分隔符“ · ”两侧空隙偏大，统一为窄空格或 4px 外边距。
16. **按钮焦点**：深色模式下点击主题按钮后，高亮底色一直停留。焦点样式只应在 `:focus-visible`（键盘操作）时出现，鼠标点击后不应保留。
17. **开发态宿主区**：浏览器独立运行时，面板左侧是大片纯白。仅在 dev 下给 body 用中性灰（或淡淡的“工作站区域”占位），方便评审时看停靠效果。不影响生产。

3. 一张卡完成 P0-2 和 P1-8，即结果页与操作区。
