# C4 先天 × 当下对照

## 目标

按原型画板 ③ 重做 `/yunqi/birth`。

## 必读

- 原型画板 ③「先天 × 当下 对照」
- `src/features/yunqi/birth/components/BirthComparisonPage.tsx`、`BirthAssessmentSession.tsx`
- `map-learning.ts` 中 `BirthComparisonViewModel`；`docs/agents/workbench.md` 出生对照与同页测评约束
- `tests/browser/birth-assessment.flows.spec.mjs`

## 要求

1. **出生输入**：公历日期 + 可选时刻（手动输入；不取 HIS）；提示文案来自 API（如“当日无交界…”）。提交后才查询；编辑或清空立即隐藏旧结果；提交中禁止重复激活。
2. **对照表**：`52px | 1fr | 1fr` 网格；列头“先天 · 出生”“当下 · 今日”，干支 `display-md` + 年份黑体 13px；行：岁运、司天、在泉、所处气、所处运；每行下方一条关系标签 + 说明（如“先天生当下 · 金生水”），标签 20px 变体，圆点 7px 变体。
3. **多候选**：时刻不详且 API 返回多个交界候选时，每个候选都完整展示并标明其规范区间，不选取单一结果。
4. **先天原文线索**：原文摘句 + 出处；“全部原文”下钻（复用 C3 的原文页结构，作用域为出生阶段）。
5. **声明**：同屏显示“出生时令结构不等于体质，原文病候是文献线索而非发病预测。请与体质量表、四诊互参。”
6. **同时测评体质**：保留现有同页测评入口与销毁语义（本卡只改入口按钮与布局；量表内部样式在 C5）。
7. 出生资料只在页面内存；不写 URL、存储；mutation `gcTime: 0` 保持。
8. 改写相关单测与 `birth-assessment.flows`、visual 用例。

## 验收标准

- 结构与画板 ③ 一致；多候选、编辑隐藏、清空、重复提交保护均通过浏览器用例验证。
- 无因果箭头、无“综合结论”；先天与当下为并列事实。
- 测试全绿。
