# C5 体质量表一题一屏 + 结果与运气互参

## 目标

按原型画板 ④ ⑤ 重做 `/yunqi/constitution` 和出生对照内的同页测评。

## 必读

- 原型画板 ④「体质量表 · 作答中」、⑤「体质结果 · 与运气互参」；组件 ScaleOption、Button
- `src/features/constitution/**`、`BirthAssessmentSession.tsx`
- `rules/CONSTITUTION-GBT46939-2025.md`（只读）；`docs/agents/workbench.md` 量表约束

## 要求

1. **顶部摘要条**：当下（干支 · 当步）与先天（若在出生对照内）各一行，只用已有 ViewModel。
2. **性别选择**：作答前选择；切换性别清空不再适用的答案和结果。
3. **一题一屏**：显示“GB/T 46939-2025 · 男/女性版 · 26 题”、`{当前}/{总数}`、13×2 进度格；题干 `question` 宋体；提示“请患者根据近一年的体验和感觉作答 · 可按数字键 1–5”；五个 ScaleOption（`radiogroup`），数字键 1–5 作答，选中后 160ms 进入下一题（`prefers-reduced-motion` 时立即）；“上一题”随时可用；无默认答案。
4. **完成态**：“26 题已全部作答”+“查看结果”（主按钮）+“返回修改”；提交后才请求评分；未完成时不发请求。
5. **结果页**：判定（`display-lg`）与兼夹；判定规则说明一句（转化分 ≥40 是、30–39 倾向是；平和质条件）；九质转化分条形（`data-primary` / `data-secondary` / `data-neutral`，30 与 40 刻度，`role="img"` 完整 `aria-label`）；九项结果分别保留，不压成单一最高分。
6. **与运气互参**：体质 / 先天 / 当下三行并列，附“三者并列呈现供医师综合判断，系统不自动辨证、不给方药。”不画箭头。
7. **操作区**：唯一次按钮“结束并销毁答卷”；**不实现**“复制结论到病历”；不实现“一键填完”。页脚注明“答卷仅存本次会话，不入库 · 结束即销毁”。
8. **出生对照内同页测评**：沿用同一组件；保持现有销毁语义（改出生资料、清空、重新对照、结束测评均销毁；旧异步评分不能回填新会话）。
9. UI 不计分、不反向计分、不选阈值；计分来自 API。
10. 改写相关单测、`birth-assessment.flows`、`workbench.flows` 量表用例与 visual 用例（原“每组 6 题”断言改为一题一屏行为）。

11. `ScaleOption` 方向键当前会选中目标项；与“选中后自动进入下一题”冲突。方向键只移动焦点，Space/Enter/数字键 1–5 才作答，并有键盘用例证明方向键不会跳题。

## 验收标准

- 键盘全流程（选择性别 → 1–5 作答 26 题 → 查看结果 → 结束销毁）通过浏览器用例。
- 结构与画板 ④ ⑤ 一致；无风险词、无红色。
- 测试全绿。
