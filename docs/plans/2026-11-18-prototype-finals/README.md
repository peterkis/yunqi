## 定稿与现行规则的调整（Claude 评审）

原型是视觉定稿，不改变仓库已确认的规则。冲突处以下表为准：

| 定稿内容 | 处理 | 原因 |
| --- | --- | --- |
| R01 条形按分数从高到低排序 | **保持标准附录顺序** | 收尾打磨 D3 已确认：按分数排序等于在 UI 新增主次判定。条形与样式按 R01，顺序不变。 |
| 结果标题旁的“倾向”标签 | 按定稿做；标题本身仍用 D3 规则 | 标题：平和质 / 单一偏颇质名 / “偏颇质兼夹”。“倾向”体质一律以 R02 染色标签（`relation-favorable`，`<名称> 倾向`，不带分数）跟在标题右侧，多个依次排列。 |
| 当下画板未画原文卡和“更多”列表 | **保留现有原文卡与“更多”列表**，放在气运卡之后，样式不变 | 画板只定稿上半屏；原文入口、其余阶段、年度详情、指定时点、计算说明是现有功能，不删。 |
| 当下画板主运 / 客运只写“水运太过 / 金运不及” | 按定稿，不带太少音名 | 音名仍在“其余阶段”和“年度详情”中可见。 |
| 年轮当前段整段实色 | 按定稿整段实色；段内进度写进 `aria-label` | 段内比例来自契约 1.3.0 的 `elapsedRatio`，不在图形上二次表达；气运列已有“还有 N 天”。 |
| 量表上下文“先天”一栏 | 有本次会话的出生资料就显示其摘要，没有就显示“未填写 · 去对照 ›” | 沿用 `ConstitutionContext` 现有的 `birth` 数据；不新增数据来源。 |
| 九质进度“气虚 2/4” | mapper 按 `scales[].items[].questionId` 统计已答题数 | 一题属于多个维度时，各维度都计入，当前题所属的全部维度都高亮。这是对 DTO 的计数，不是判定。 |
