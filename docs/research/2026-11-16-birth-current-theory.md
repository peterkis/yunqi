# 出生运气与当前运气联合解释：文献依据及本轮实现边界

- 核查日期：2026-11-16（北京时间）。
- 工程基线：`d31e038f4b6c5650288063cf44d52d267a01494a`。
- 性质：针对本次功能的原始资料核查与工程建议，不是系统综述、专家共识或临床验证报告。
- 任务：继续五项医生反馈中出生/当前运气的学习能力；不把文献关联性自动升级为个人疾病结论。

## 1. 可直接执行的结论

本轮可以补充**经典病候原文、阅读提示以及出生与当前的对读**。现有52条摘录中的不少内容只录入气候、物候或岁运首句；对应原典段落还包含病候。补充这些文本能直接回应老师希望理解临床语境的需求，选取条件仍为已有岁运五行/太过不及、司天和六气阶段，不需要新增个人疾病推断规则。[R1]、[R2]；工程基线见[现有摘录实现](../../packages/yunqi-domain/src/learning/passages.ts)及[学习规则](../../rules/LEARNING_RULES_V1.md)。

出生与流年联合解释确有现代研究，并非“没有相关文献”。其中2025年原始研究将胎孕期禀赋与后续各年急诊情况比较，另一博士论文研究出生及发病时的运气组合。它们的分组、终点和数据口径与本项目“出生时点快照＋当前时点快照”不等价，不能直接变成通用疾病列表或概率。[R6]、[R7]

在本次已访问资料中，尚未取得同时具备明确适用人群、完整可复现规则或模型、前瞻时间窗及外部验证材料的“仅凭生日和当前日期推断个人体质及易患疾病”规范。此结论是**本次证据不足**，不等同于证明此类研究或规范绝不存在。原有第4项“个体推断未实现”的范围说明仍应保留。

## 3. 原典短证据与上下文

### 3.1 《气交变大论》中的“先天”不是这里的出生体质

该篇先讨论岁气太过、不及的来临先后，有短句“**太过者先天，不及者后天**”。随后逐一说明岁运的气候、病候及其他条件。因此，同一“先天”字样在这里属于气化时序，不应因为用户页面称“先天运气”就把它当作出生体质的直接证明。[R1]

本轮2026年水运太过的原典段，在气候与心火关系之后还出现“**民病身热烦心躁悸**”。适合显示为**该岁运原文所述病候**；不适合改写成“该用户容易患某现代心脏病”。该段后文另有程度、上临等条件，摘录时不能把条件句拆成无条件个人结论。[R1]

### 3.2 《六元正纪大论》必须按司天及阶段定位

该篇以“**先立其年以明其气**”开始次序化说明。少阴司天五之气的段落同时有“**民迺康，其病温**”，不能只取前半句表示健康保证，也不能只取后半句变成确定的个人温病预测。[R2]

现有匹配设计“司天＋六气步序”合理；只按当前客气检索全文会混入其他司天组的语境。年度、阶段和出生候选应分别保留来源标识，不把不同段落拼成一条“原文”。

### 3.3 电子文本需要保留见证身份

本次可全文读取的两份经典见证为维基文库《素问》第二十、二十一卷，亦是当前`CLASSICAL_SOURCES`登记的文本。它们是公版原典的电子转录，**不是已经完成专家校勘的指定出版版次**。[R1]、[R2]

读取中能见到疑似转录或字形问题，例如胁部语境中的“恢”、括号式缺字表示，以及迺、欬等异体。不要凭模型猜测静默改字：保留原见证字形，或另行核对明确版次后记录异文和校改理由。原文与白话阅读说明须继续分开。

补充检索可见中国哲学书电子化计划《气交变大论》的“肌肉瞤酸”“膕腨股膝不便”等异文，以及《素问补注释文》关于先天/后天为气化先后时序的注解。但本次直接打开返回403，仅取得搜索索引，未核其影印或全文；这些线索不足以支持本轮静默替换已选见证的疑字。[R9]、[R10]

## 4. 现代原始研究能支持到哪一步

### 4.1 体质关联研究

韩玲等2019年研究使用在校生体质问卷，分析其中900名平和体质者的出生运气因素，报告统计关联。它可作为“有人研究这一问题”的依据，不能据摘要建立覆盖所有年龄、九类体质的生日判定表；研究先以问卷确定体质，再分析出生因素，并非验证了以生日替代问卷的工具。[R3]

### 4.2 特定疾病样本

陈冉等2023年DKD研究比较1698例病例与3740例对照，两组均来自2型糖尿病住院患者。该研究人群和终点不能直接推广为普通人的肾病概率。已取得的摘要还有天干与五行表述冲突：摘要将丙标为木太过，而本项目规则中丙为水太过；搜索索引的正文片段则提到壬。未完成原版全文校勘前，不应自动抽取这些数值作为规则。[R4]

韩奇成等2024年胃癌研究纳入668例病例，摘要明确报告多项岁运/主客运等分布差异无统计学意义，同时另有分组结果显著。不能只挑“比例最高”或显著子组，转换成任意用户的胃癌风险标签。[R5]

### 4.3 联合禀赋与流年的研究确实存在

李坤辰等2025年文章比较北京医保急诊患者与北京市常住人口资料，采用**胎孕期禀赋**分组，研究流年下的急诊率变化。作者讨论母子五行及司天/在泉的联合关系。这是值得科室审阅的直接相关文献，但终点是急诊利用/就诊率，分组也不是本项目单一出生时点；其摘要没有提供可直接部署的、疾病特异的个人预测模型。[R6]

张玉鑫2025年博士论文摘要报告基于21.46万住院病例，以出生和发病运气特征建立随机森林，按3:1划分训练/测试集；大寒口径下两个测试AUC约为0.626与0.712。本次只取得摘要，未取得完整特征处理、模型文件或外部验证材料。[R7]

**工程推论：**已知发病日期参与的病例模型，不能未经论证就把“当前日期”当作同一特征来回答未来某个时间窗是否发病。病例对照样本中的分类表现也不直接给出一般人群的绝对概率。若科室选择这些研究作为下一阶段依据，需先取得完整方法及数据定义，并单独设计验证。

## 5. 本轮内容增量建议

以下为工程设计建议，不是新增医学事实或已获专家认可的规则。

1. **补齐上下文。** 保持52个现有匹配位置，年度/阶段摘录补入已经核对的病候原文。气候、病候和原条件尽量连续；治法、方药、剂量及疗程不进入本轮摘录。
2. **用原文说清楚观察对象。** 标题可用“经典病候对读”“该岁运原文所述病候”；阅读说明解释“本段谈什么”，避免改写为“你将出现什么”。
3. **出生与当前各自呈现。** 两侧分别使用实际候选的年度与阶段资料。未知时刻有多个候选时，保留候选及边界，不合并成单一风险。
4. **不强造病候内容。** 原典相应阶段没有具体病候时，可以说明“本段未列具体病候”；这不表示零风险，也不从其他阶段补一条。
5. **术语释义逐条有依据。** 原文古代病名与同名现代疾病不能默认一一对应；未校核的词先保留原文。白话提示明确属于工程阅读说明，不冒称权威译本。
6. **同页量表保持独立。** 若把量表嵌入出生页面，仍按[既有量表规则](../../rules/CONSTITUTION-GBT46939-2025.md)的26个适用输入计算，出生日期和当前时气不得改动量表分数。
7. **版本和证据。** 扩展经典正文/阅读说明时递增经典内容版本，记录所据电子见证、核对日期、摘录范围及专家状态。历史验收报告保留原样。

### 建议验收点

- 全部52个匹配位置仍唯一、可追溯，年度/司天/阶段不串组。
- 引文与选定见证逐段一致；被省略的治法等内容不被伪装成原文连续部分。
- 无病候的阶段不生成医学症状、病种、风险等级或概率。
- 出生/当前两个时点及出生边界候选的文本随真实输入变化，编辑输入后旧结果失效。
- 量表嵌入与独立入口使用同一计分行为，切换、清空、离开后的资料边界一致。
- 覆盖窄屏、键盘、折叠阅读、长古文换行；第一屏仍以年度与当前阶段为主。
