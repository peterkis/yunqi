# 运气通 0.2.0 · Rust 迁移与 Windows 验证

2026-11-27。项目目录为 `D:\Projects\YunQi-rust`，本地分支为 `rust/native-desktop`。业务基准为 `peterkis/yunqi@7d6ce9b532407322faffb9f51e31455c394dd69d`。桌面外壳及对应的 React 工作台取自 `D:\worktrees\yunqi-desktop-updates` 的 0.1.10 本地工作树。Windows A/B 对照使用从该版本离线包实际提取的可执行文件。机器原有 0.1.9 安装保留作日常使用。

## 使用

| 用途 | 项目内入口 |
|---|---|
| 直接试用 Windows 桌面版 | `desktop\src-tauri\target\release\yunqi-sidebar.exe` |
| x64 离线安装包 | `desktop\src-tauri\target\release\bundle\nsis\运气通_0.2.0_x64-setup.exe` |
| 独立运行 HTTP，默认绑定 127.0.0.1:3000 | `native-http\target\release\yunqi-http.exe` |
| 构建离线安装包 | PowerShell 7 执行 `.\desktop\build.ps1` |
| 重跑 Rust 核心、契约、时间和 HTTP 模块测试 | `pnpm test:native` |
| 重跑完整对照 | `pnpm verify:native --exhaustive`，自动在项目内检出固定提交并构建参考实现 |
| Windows 证据目录 | `.artifacts\native-verification\` |

显式设置 `HOST=localhost` 时，独立 HTTP 服务监听解析所得的可用 IPv4 / IPv6 回环地址，两个地址共用端口（包括 `PORT=0`）和全局资源预算。未设置 `HOST` 时仍仅绑定 `127.0.0.1`。

桌面直接调用 Rust 计算，无需单独启动 HTTP 服务。Tauri 继续负责窗口、置顶、贴顶、托盘和院内更新客户端。React 工作台、浏览器 DTO 和客户端继续使用既有展示代码。TypeScript 业务包保留供工程对照和 OpenAPI 生成；独立的院内更新分发工具也保留原实现。生产桌面安装包使用编译好的静态工作台资源。

## Windows 发布程序同机对照

同一台 Windows 11 Pro 10.0.26300、Core i7-1260P、WebView2 158 设备。旧版和新版各启动 3 次，交替执行，使用独立 WebView2 配置。每轮通过真实 WebView → Tauri 调用；每项预热 1 次，再测 30 次，每版本每项共 90 次。请求间隔 80 毫秒。首页就绪要求页面已渲染且实际年度查询返回 200；启动数据以 3 次的中位数报告。

内存采用整棵应用进程树的私有工作集（常驻且不共享的内存），单位 MiB。首页就绪后静置 2 秒测一次，完成操作再静置 2 秒复测。每个状态分别取 3 次中位数。

| 指标 | 旧版 0.1.10 | Rust 0.2.0 | 变化 |
|---|---:|---:|---:|
| 首页空闲 · 整棵进程树私有工作集 | 277.63 MiB | 200.31 MiB | 减少 77.32 MiB（27.85%） |
| 连续查询后 · 整棵进程树私有工作集 | 236.22 MiB | 188.42 MiB | 减少 47.80 MiB（20.24%） |
| 首页空闲 · Node 私有工作集 | 75.73 MiB | 0 MiB | 减少 75.73 MiB |
| 首页空闲 · WebView2 私有工作集合计 | 195.27 MiB | 194.62 MiB | 约 0.64 MiB |
| 进程数 | 9 | 7 | 去除 node.exe 和 conhost.exe；两版各 6 个 WebView2 进程 |
| 首页首次可查询，中位数 | 2.825 秒 | 1.092 秒 | 缩短 1.733 秒 |

| 真实桌面调用，每格为 P50 / P95 | 原版 | Rust |
|---|---:|---:|
| 年度查询 | 5.0 / 6.7 ms | 3.6 / 4.3 ms |
| 指定时刻教学 | 6.8 / 8.6 ms | 4.1 / 4.9 ms |
| 农历生日预览 | 8.7 / 11.0 ms | 4.0 / 4.9 ms |
| 体质量表评分 | 4.7 / 5.6 ms | 3.4 / 4.0 ms |

首页空闲阶段的内存收益基本可由 Node 消失解释。运行一轮后旧版 Node 的私有工作集降至 46.60 MiB，同一阶段整棵树的差值也降至 47.80 MiB。各次 Windows 采样的进程树、私有提交量、工作集与每次调用的原始时间保存在 windows-desktop-benchmark.json。
