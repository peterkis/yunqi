# Windows 0.2.3 正式版 · 离线字体与安装包

0.2.3 将已在 Windows 预览版验收的字体方案用于正式工作台，保留正式应用标识 `cn.yunqi.offlinepilot`、单实例处理和院内更新入口。用户可用新版安装程序升级原“运气通”。字体预览版使用另一应用标识，已安装的预览版可独立卸载。

## 正式字体

本机真实 WebView2 158.0.4370.33 在 400×1019、100% 缩放下分别打开当下运气、先天对照和体质量表。各默认页实际读取常用黑体 304,892 B 和常用宋体 404,068 B，合计 708,960 B；从应用本地来源读取的两份派生字体、两份完整原字体和 OFL 许可均与获准预览版的 SHA-256 一致。对具体字形的检查确认“甲”使用两款常用字体，“龘”由对应的完整原字库绘制。完整原字库仍随包分发，首屏字体读取量与安装程序体积应分开看待。[离线字体规范](design/README.md#工作台离线字体)

生产构建保留了当前业务 JavaScript 内容，以及字体声明以外的样式。两组共 4 条 `@font-face` 声明验证了互补的 Unicode 范围、400–700 可变字重和 `font-display: swap`。更新字表时使用 [字符表](../apps/yunqi-workbench/scripts/ui-font-characters.txt) 和 [生成脚本](../apps/yunqi-workbench/scripts/build-ui-fonts.py)。普通构建直接使用工作区内随源码分发的字体文件。

## 验收记录

- 最终包内程序通过 10 项契约操作、输入错误、固定北京时间、农历预览、年度与出生对照、时间线、指定时点键盘、26 题作答评分及销毁。业务验收实测从 400×1019 展开切换到 424×78 胶囊，再返回展开。关闭时确认自有进程全部退出、窗体偏好摘要与启动前一致。
- 六组专项网页验收覆盖浅色和深色，以及完整、减少和关闭动效，检查三个主要入口的冷启动字体请求和两种家族的实际回退。设计组件测试页另含 U+202F 窄不换行空格，该字符可在本机触发完整黑体；验收按页面实际字形区分请求。
- 工作台生产构建、生产和测试类型检查、字体专项单元测试（8 项）、项目指引（15 项）和 Workbench 治理（312 项通过，Windows 符号链接权限条件下跳过 1 项）通过。本轮调整的是工作台字体及发布版本，业务规则、量表计分和 API 契约沿用上版。
- 只有字体维护者需要 fontTools 等生成依赖。在隔离目录用正式字表重新生成，两个派生 WOFF2 及四条 CSS 声明均与随源码分发的文件逐字节相同。
- 本次在同一台 Windows 上用普通 Release 和独立 WebView 用户目录各启动一次，未开启 DevTools 或 CDP。400×1019 浮窗在展开 40 秒后，0.2.2 与 0.2.3 全树私有工作集分别为 160.10 与 116.00 MiB，私有提交为 252.23 与 176.66 MiB，renderer 的私有工作集为 66.37 与 28.25 MiB。两次背景 CPU 快照约为 28% 与 72%，新版采样与网页测试并行。这组数值用于复核改善方向，不能作为其他设备的固定节省量。

### 全量网页回归

网页矩阵使用仓库配置的 Vite 与 Fastify 测试服务。桌面程序的验收单独运行安装包内的 Rust Release。Playwright 在两个 worker、零自动重试下完成 519 项，耗时 41 分 48 秒。初跑 504 项通过、8 项失败、7 项按项目条件跳过。170 项视觉、布局与无障碍验收、6 项字体专项验收均通过。与 0.2.1 的 519 项基线逐用例比对，其中 6 个曾通过的用例按原阈值、单 worker 复测，6 项全部通过。三项长流程分别在 23.5、18.6、23.0 秒内完成，一项量表答题中位数降至 265.7 毫秒，另两项指定时间页在初跑时记录到 Chromium 请求同源组件报 `ERR_NETWORK_CHANGED`。

原有的两项性能门槛在本轮仍未通过。关闭动效时，量表答题推进中位数为 325.6 毫秒，门槛为 290 毫秒。CPU 模拟降速 20 倍时，返回“当下运气”的交互触及 90 秒整案超时；0.2.1 在同一交互触及 10 秒点击动作超时。首轮与单独复核的结果分别保存在 `.artifacts/font-release-0.2.3/browser-matrix/results.json` 和 `browser-recheck/results.json`（同一发布产物目录），保留原始统计和阈值。

### 工作台单元测试与覆盖率

独立运行工作台的 V8 覆盖率套件，单 worker、原有超时及覆盖率门槛，87 个文件、779 个测试全部通过，耗时 348.36 秒，退出码 0。语句、分支、函数、行覆盖率分别为 94.23%、92.29%、94.83%、96.11%。早期与浏览器全量并跑时，覆盖率任务连续八分钟没有完成新的文件，终止该次任务并保留退出码 124；五组定向用例在并跑环境复测通过 74/75。完整独立运行覆盖了同一批用例。各轮日志见 `.artifacts/font-policy-release/`，最终日志为 `workbench-coverage-final.log`。

## 旧介质清理

新包通过开包校验与独立程序验证后，按原文件名及 SHA-256 清理了 5 份旧版运气通安装包，共 1,000,945,311 字节，包括 0.2.1 正式包、0.2.2 正式包与恢复打包副本，以及字体预览包的构建和交付副本。正式交付目录只保留上述两个 0.2.3 安装程序及校验文件。历史测试报告、微软运行时构建依赖和用户已安装的软件继续保留。
