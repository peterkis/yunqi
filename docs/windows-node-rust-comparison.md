2026-11-27 在同一台 Windows 11 专业版 10.0.26300、Core i7-1260P、16 个逻辑核的设备上，直接启动从两个 x64 NSIS 离线安装包解出的正式程序。业务对照基准为 `7d6ce9b532407322faffb9f51e31455c394dd69d`。旧桌面原型来自独立的 0.1.10 工作树，远端同一提交的主线提供 TypeScript 业务及网页工作台。

## 普通展开启动

两端均使用空的独立 WebView2 用户目录，在浮动展开状态采样。顺序为旧、新、新、旧、旧、新，各启动三次。采样脚本识别本次进程拥有的可见窗口及其 WRY WebView，在 20 秒和 40 秒记录实际窗口大小和进程树。六次均为 400 × 1020，均未开启 DevTools 或连接 CDP，脚本在每轮对 WebView2 命令行检查调试开关。计量为自有进程的私有工作集，单位 MiB。机器的系统文件缓存、后台进程保持正常运行。

| 启动顺序 | 版本 / 轮次 | 20 秒私有工作集 | 40 秒私有工作集 | 20 秒 / 40 秒自有进程数 | 启动时整机 CPU |
| ---: | --- | ---: | ---: | ---: | ---: |
| 1 | 0.1.10 / 1 | 190.15 | 146.07 | 9 / 7 | 20% |
| 2 | 0.2.3 / 1 | 123.43 | 122.59 | 7 / 7 | 18% |
| 3 | 0.2.3 / 2 | 118.40 | 117.68 | 7 / 7 | 39% |
| 4 | 0.1.10 / 2 | 194.30 | 193.91 | 9 / 9 | 34% |
| 5 | 0.1.10 / 3 | 202.24 | 201.96 | 9 / 9 | 15% |
| 6 | 0.2.3 / 3 | 119.77 | 118.94 | 7 / 7 | 6% |

三轮中位数在 20 秒由 194.30 降至 119.77 MiB，减少 74.53 MiB（38.36%）。40 秒由 193.91 降至 118.94 MiB，减少 74.97 MiB（38.66%）。40 秒全树私有提交量中位数由 293.80 降至 180.50 MiB，renderer 私有工作集由 69.68 降至 24.97 MiB。该差值同时包含移除 sidecar、工作台字体加载和两版的其他改动。

各次关闭后自有进程句柄均退出，窗口偏好经字节比对恢复。两个版本在每个时点均测到六个 WebView2 进程。旧版第一轮 20 秒时测得 Node 和控制台宿主，40 秒快照未再观察到这两个进程，其他两轮在两个采样点均有它们。该原样本保留在中位数中，现有记录无法确定这一变化的原因。新版六个采样点均为一个 Rust 宿主与六个 WebView2 进程。普通采样只记录窗口和进程，业务就绪由下面的独立交互诊断验证。

## 访问业务操作

另各启动一次正式程序，用本机环回 CDP 连接两端实际的 400 × 1020 WebView。脚本要求工作台渲染，且年度查询真实返回 200，再记录首次可查询时间。旧版为 1.857 秒，0.2.3 为 0.722 秒，每版只有一个启动样本。随后按相同顺序实测四类 Tauri 调用，每类先预热一次，再取 30 笔，每版共 120 笔；每笔校验 HTTP 语义状态 200 和成功信封。两端均成功，脚本退出码 0。此组连接调试协议，内存结论采用上面的普通启动组。

| 实际交互，毫秒（P50 / P95） | Node 0.1.10 | Rust 0.2.3 |
| --- | ---: | ---: |
| 年度查询 | 4.4 / 5.3 | 3.0 / 3.9 |
| 指定时刻教学 | 5.8 / 6.8 | 3.4 / 4.7 |
| 农历生日预览 | 6.8 / 7.7 | 3.2 / 5.2 |
| 体质计分 | 4.1 / 5.4 | 3.0 / 3.9 |

旧版在该组的首次就绪和最后一次采样都检出了 Node，且四类业务实际返回成功。普通组执行期间另外用旧包的原配 worker 单独验证过一次年度请求，返回 200，这一诊断可能影响旧包的磁盘缓存。并行工程检查与启动时整机 CPU 的波动会影响单机结果。两个版本普通组的正常关闭已分别核验，业务诊断脚本在等待窗口关闭超时后终止了本轮两个自有程序。

## 复现

两份解包的主程序分别放在独立目录，旧版保留其原配 `runtime`。在 Windows 上用 Python 3 和工程的 Playwright，从仓库根目录运行以下命令。结果目录须预先存在，各输出文件名须为新文件。普通采样的操作顺序与上表一致，每轮分别替换可执行文件、摘要和编号；分析时保持两端相同展开尺寸。

```powershell
python native/verification/windows-dock-memory.py $oldExe $result/old1.json --short --label old --cycle 1 --sha $oldSha
python native/verification/windows-dock-memory.py $rustExe $result/rust1.json --short --label rust --cycle 1 --sha $rustSha
node native/verification/windows-desktop-benchmark.cjs $oldExe $rustExe $playwrightCore $result/business.json 1
```

本机原始记录放在 `.artifacts/pr-readiness-023/desktop-direct/`，包括六次完整进程树、窗口偏好复核、启动时整机 CPU 快照及单独的业务诊断。各版的规则与契约回放见[迁移报告](rust-migration.md)，单独测量字体变化见[0.2.3 正式版记录](windows-0.2.3-fonts.md)。这些测量反映本机的启动与短时交互，多终端门诊负载和长期驻留需另行采集。
