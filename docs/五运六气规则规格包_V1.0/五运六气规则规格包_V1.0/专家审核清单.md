# 中医专家审核清单

> 用途：由中医专家审核员对《五运六气规则规格说明书 V1.0》逐项确认。  
> 状态建议：`待审核 / 通过 / 有条件通过 / 驳回 / 存在流派差异`。

## A. 历法和年界

- [ ] MVP 采用 Asia/Shanghai 时区是否合适？
- [ ] 运气年以“大寒精确交节时刻”为边界是否确认？
- [ ] 大寒前归上一运气年、大寒时刻起归当年运气年的定义是否确认？
- [ ] 年干支按“运气年数值”推算，而不随春节或立春切换，是否确认？
- [ ] 六步边界采用大寒、春分、小满、大暑、秋分、小雪精确交节时刻，是否确认？
- [ ] 所有时间区间采用 `[start, end)` 是否确认？

## B. MVP 五运规则

- [ ] 甲己土、乙庚金、丙辛水、丁壬木、戊癸火是否确认？
- [ ] 阳干太过、阴干不及是否确认？
- [ ] 五音映射（角、徵、宫、商、羽及太少）是否确认？

## C. MVP 六气规则

- [ ] 子午少阴、丑未太阴、寅申少阳、卯酉阳明、辰戌太阳、巳亥厥阴是否确认？
- [ ] 司天与在泉对应表是否确认？
- [ ] 主气固定次序是否确认？
- [ ] 客气三阴三阳次序是否确认？
- [ ] 司天居三之气、在泉居终之气是否确认？
- [ ] 四间气前后轮转算法是否确认？

## D. 客主关系

- [ ] 同气、主生客、客生主统一标为“相得”是否确认？
- [ ] 主克客表述为“主胜客，逆”是否确认？
- [ ] 客克主表述为“客胜主，从”是否确认？
- [ ] 是否需要保留“相得而和 / 相得而病”等更细分概念到二期？

## E. 二期规则

- [ ] 主运五步及太少排法是否确认？
- [ ] 主运各步传统交司时刻是否确认？
- [ ] 客运以岁运为初运、太少相生交替是否确认？
- [ ] 天符、岁会、太乙天符、同天符、同岁会年份集合是否确认？
- [ ] “太过先天十三日、不及后天十三日”应如何在系统中表达？
- [ ] 平气判断是否按实际物候校正，还是仅展示理论标记？
- [ ] 胜复、郁发、南北政、标本中气是否进入二期，顺序如何？
- [ ] 不同学派规则是否需要并存并可切换？

## F. 医疗安全与文字

- [ ] 所有解释是否只作为传统理论背景？
- [ ] 是否存在被误解为自动诊断、疾病预测、处方建议的表述？
- [ ] 是否需要增加经典出处或教材出处？
- [ ] 是否允许面向患者展示？若允许，哪些术语必须改写？
