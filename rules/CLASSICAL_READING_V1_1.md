## 1. 调整目的和边界

前版部分摘录仅取了气候开头，老师无法在同一段中阅读经典病候。本次逐条核对全部 52 则：10 则岁运、6 则司天年度、36 则“司天 × 六气阶段”。其中 32 则扩大原文范围（10 + 6 + 16），20 则维持原文范围；52 则均更新工程阅读说明。所有 ID、匹配键、顺序、条目数和 `isExcerpt` 标识保持不变。

本次补的是可追溯的文献阅读材料。年度和阶段病候不转换成出生体质、现代疾病、个人易患病清单或风险概率。古典“肝木、脾土、肾水”等不直接等于现代解剖器官疾病；“霍乱、温病、温厉”等不直接等于现代同名或相似名称的诊断。复杂词语无法可靠解释时保留原词，并说明需要校勘或进一步研读。[S1]、[S2]

“先天／后天”在这些气化段落中涉及运行先后，不能作为生日确定先天体质的证据。出生与当前联合研究及适用限制另见[研究记录](../docs/research/2026-11-16-birth-current-theory.md)；本次没有引入该类预测模型。

## 3. 选段与阅读说明规则

1. 同一摘录不拼接不相邻句子，不加入原典没有的省略号或改造标点。截在原逗号处的条目仍保留逗号，并由 `isExcerpt: true` 与界面的“摘录”标识说明未完结。
2. 气候、病候与已纳入选段的条件必须一起保留，包括“感于寒湿”“感于寒则”“甚则”等。未选入的“上临某气”“复则”等后续段落，不拼到本条通用病候之后。
3. “民迺康”“民迺和”“民气和平”之后若有病候，不能在前半句截断。少阳二气、少阴二气与五气、阳明终气等保持前后连续语境。
4. 原段没有另列病候时不补疾病。太阳五气、阳明五气、厥阴五气保持原范围；少阳五气仅包含原典寒雨与避寒行为，不把阅读材料生成个体调养方案。
5. 本次产品选段不含治法、方药、剂量，也不输出古典死亡或妊娠预后断语。摘录的终点与未录部分在下表和阅读说明中公开，不能声称完整转载整篇。
6. 工程阅读说明帮助辨认段落结构、寒热并见和条件，不冒充古文全译或经专家确认的术语辞典。不从日期判断读者具有原典病候。

岁木、火、土、水太过的摘录分别止于首组病候及其星象结句；金太过止于“目赤痛眦疡耳无所闻”。其后“甚则”“上临”等更长条件段不混入本轮通用选段。[S1]

太阳三气止于“心热瞀闷，”而不录其后的“不治者死”；太阳终气止于“寒风以至，”而不录其后的妊娠预后句；阳明二气仍保留“厉大至，”但不录随后死亡句；少阳三气止于“喉痹目赤，”而不录随后死亡句。这样既不把原段截成健康保证，也不让界面按日期显示个人死亡、妊娠或预后判断。[S2]

年度少阳止于第一组病候“内为泄满，”；没有跳过“故圣人遇之，和而不争”后再拼入“往复之作”的另一组病候。太阴年度止于“痞逆寒厥拘急，”；年度后续论述仍可从原典链接查阅。[S2]

各终气在调治句前结束：阳明止于“其病温”，少阳止于“阳气不藏而欬”，太阴止于“寒湿推于气交而为疾也”，少阴止于“下连少腹而作寒中地将易也”，厥阴止于“其病温厉”。这些终点保留电子见证的标点；不为阅读顺畅静默修订句读。[S2]

## 6. 迁移和接口影响

`calculateLearning()` 的匹配逻辑不变：岁运按五行与太过／不及；年度气按司天；阶段按“司天 + 六气序号”。全部 52 个 ID 与匹配字段保持不变，出生与当前时点可复用同一计算。

经典内容有独立数据版本。`calculateLearning().notes` 在现有字符串数组中携带 `YQ-CLASSICAL-READING-1.1.0`，让既有 API 消费者能够追溯文本版次。没有新增 DTO 字段、端点或 Contract 版本；`ruleVersion` 仍代表教学计算规则，不能把它当作经典文本版次。

消费者需要接纳更长的 `quote`、新的 `explanation` 和包含版本的说明文字，不应依赖旧摘录全文作为键、截取某个“民康”词作为结论，或把原典病候转成结构化疾病风险。核心计算、边界判断、出生候选划分和量表计分均未变更。

本轮 Domain 包仅提升补丁版本到 1.3.1；经典数据由 1.0.0 提升至 1.1.0。专业校勘和术语释义仍需中医专家签审，本次工程比对不替代该步骤。
