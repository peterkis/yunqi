## 题目与量表映射

按原文近一年体验作答，每题1–5分。完全相同的问句合并为一个输入，同一答案按各分量表方向独立计分，避免重复填写产生矛盾。本表题目 ID 是工程标识，不是标准原有编码。

| 标准表 | 类型 ID / 名称 | 计分题目 ID（原文顺序） | 适用条目数 |
| --- | --- | --- | --- |
| A.1 | balanced / 平和质 | energy、fatigue*、low_mood*、cold_intolerance* | 4 |
| A.2 | qi_deficiency / 气虚质 | fatigue、short_breath、palpitations | 3 |
| A.3 | yang_deficiency / 阳虚质 | cold_body、extra_clothes、cold_intolerance | 3 |
| A.4 | yin_deficiency / 阴虚质 | body_heat、dry_skin_lips、flushed_cheeks | 3 |
| A.5 | phlegm_dampness / 痰湿质 | body_heaviness、soft_abdomen、sticky_mouth | 3 |
| A.6 | damp_heat / 湿热质 | oily_face、dark_urine、yellow_discharge（女）或 damp_scrotum（男） | 3 |
| A.7 | blood_stasis / 血瘀质 | body_pain、dark_complexion、dark_lips | 3 |
| A.8 | qi_stagnation / 气郁质 | low_mood、anxiety、emotional_sensitivity | 3 |
| A.9 | special_diathesis / 特禀质 | sneezing、allergy、urticaria、scratch_marks | 4 |

`*` 为反向题，仅在平和质中按 `6 - 答案` 计分。同一个 fatigue 在气虚质中仍按原答分计入。题库包含27个不同题目，其中两题分别限女/男，单次适用26个不同问题；九个分量表合计29个计分条目。题数、计分条目数和分量表数不得混写。

性别仅用于选择标准A.6的适用条目，不形成患者档案。未选择或无法选择适用项时保持未完成，由医师确认，不能把不适用题记为1分。选择改变后前端必须移除原性别限定题的答案。API拒绝同时提交两道限定题，也拒绝未答、未知题、答案数组或非1–5整数。

## 计分与判定

先按分量表完成反向处理，再求原始分。转化分计算为：

`100 × (原始分 - 适用条目数) / (4 × 适用条目数)`。

数值判定直接比较整数分子和阈值乘分母；先判定，之后才能为展示四舍五入。保留原始分、条目数及未舍入转化分，便于复算。

| 类型 | 条件 | 结果 |
| --- | --- | --- |
| 平和质 | 本类≥60，其他8类全部<30 | 是 |
| 平和质 | 本类≥60，其他8类全部<40，且未满足上一行 | 基本是 |
| 平和质 | 其余 | 否 |
| 其他8类 | ≥40 | 是 |
| 其他8类 | ≥30且<40 | 倾向是 |
| 其他8类 | <30 | 否 |

标准表1写作“30分～39分”；本实现按连续转化分区间 `[30,40)` 表达，未先取整。2025版3题和4题分量表的可达分值分别以 `100/12` 和 `100/16` 递增，不会产生39与40之间的可达分值。

多类同时达到“是”时均保留，显示兼夹；不只取最大值，也不因同分任意择一。“基本是平和质”可以和某类倾向并存。若平和质未达条件、偏颇质又均不足40，报告未达到明确类型条件并保留存在的倾向，不自动归为平和质。

## 运行和产品边界

- 纯Domain负责版本化题目、映射、计分和结果。React只负责作答与显示，Service定义和验证契约。
- 本功能不保存身份、生日、题目答案或结果；输入和结果只为本次会话使用。
- 结果表述为量表判定，反映近一年自报体验，不解释成生日决定的先天体质，也不组合成个人疾病概率。
- 不内置药物、方剂、剂量、疗程或治疗推荐。适用人群、代答以及特殊人群的解释由医师确认。
