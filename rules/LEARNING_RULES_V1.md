## 1. 三种关系不能混算

| 层级 | 比较对象 | 输出 |
| --- | --- | --- |
| 年度相临 | 司天五行与中运五行 | 顺化、天刑、小逆、不和、天符 |
| 当步加临 | 当步客气与主气 | 生克方向、相得、主胜客逆、客胜主从、君相火特例 |
| 出生与当前 | 同一维度的出生五行与当前五行 | 明确“出生生当前”等方向，不套年度或客主专用术语 |

年度取《医宗金鉴》卷三十五六十年运气上下相临歌：司天生运为顺化，司天克运为天刑，运生司天为小逆，运克司天为不和，同五行为天符。仅取司天，不用在泉代替；不推导岁会、同天符或太乙天符。

客主取《素问·至真要大论》“主胜逆，客胜从”及《六微旨大论》“君位臣则顺，臣位君则逆”。客少阴君火加临主少阳相火为顺，反向为逆，优先于同五行处理。相生保留两个方向并标相得，不对有文献分歧的相生一律定顺逆。同气不是健康保证，顺逆不是疾病严重度。

2026丙午的独立校验：中运水太过，少阴君火司天，年度水克火为不和；2026-11-16五之气主阳明燥金、客少阳相火，客火克主金为从（顺）。两者同时成立。

## 2. 五步运

### 太少与次序

主运按木、火、土、金、水排列；甲乙丙壬癸从太角起，丁戊己庚辛从少角起，木至水按太少相生。
客运采用《素问·六元正纪大论》各年明列五音次序：从本年岁运所在项起旋转主运五项。水到木处不机械翻转太少；例如丙年为太羽、太角、少徵、太宫、少商。
这与其他文献中的另一种推法存在差异，本轮选定《素问》列举口径，不能暗中混用。

### 交运边界：TERM_OFFSET_TEACHING_V1

| 边界 | 本轮精确定义 |
| --- | --- |
| 初运开始 | 当年大寒实际交节时刻 |
| 二运开始 | 春分交节时刻加13个固定北京时间日 |
| 三运开始 | 芒种交节时刻加10个固定北京时间日 |
| 四运开始 | 处暑交节时刻加7个固定北京时间日 |
| 终运开始 | 立冬交节时刻加4个固定北京时间日 |
| 终运结束 | 次年大寒实际交节时刻 |

固定北京时间日为24小时，保留交节钟点，不含起日计数；全区间左闭右开。五步运与六步气分别查找归属，不能复用阶段索引。

此算法是对《医宗金鉴》节令口诀的**现代教学工程解释**，原典没有直接规定现代交节秒数加整日的方法。它不等于《类经图翼》的古代每运73日5刻法，也不等于现代实际大寒年五等分法。古百刻制五刻为72分钟，不能按现代15分钟一刻计算。页面必须明示“教学口径、待专家确认”；正式使用前由中医老师确认采用哪套交运口径。

## 3. 原文匹配

52条摘录分为岁运五行×太过/不及10条、司天之政6条、司天×六步36条。年度提取实际岁运及司天两条，阶段同时使用司天和步序匹配，不仅按客气检索。原典病候是文献内容，不能改写为当前使用者的疾病预测。原文、现代阅读释义、出处链接分开。

数据与出处登记在 [sources.ts](../packages/yunqi-domain/src/learning/sources.ts) 和 [passages.ts](../packages/yunqi-domain/src/learning/passages.ts)。年度首句属于摘录，不冒称完整章节或用户未提供的某本教材版本。

## 4. 出生对照

输入公历生日，可选时分秒；业务时间沿用固定UTC+08，不做农历转换或历史夏令时还原。已知时间只计算一次；不详则划分该日内所有年界、气界、运界，出现多种归属必须保留候选。内部取样点不作为出生时间展示。未来出生输入拒绝；当日只分析已经发生的时段。

候选区间统一左闭右开。系统时间精度为毫秒；生日为今天时，区间必须包含请求当前毫秒，因此右开上界取“当前时刻的下一毫秒”与次日零时的较早者。这个上界只是区间表示，不是允许未来出生输入；区间内没有晚于当前毫秒的有效时点。零时查询也保留当刻，不能产生空区间。取末段归属时使用上界前一毫秒，不把右开终点当作区间内样本。

支持范围沿用1900–2100运气年。1900大寒当天零时尚属1899年，日期不详请求不能给出完整日结论，须输入有效范围内的已知时刻；不静默丢掉不支持时段。

出生时令结构不等于九种体质。对照只提供明确方向与经典线索，不提供具体疾病发生概率、风险分级、自动辨证或方药。体质由独立量表与医师评估互参。
