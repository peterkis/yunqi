# 运气教学解释规则 1.3

- 版本 `YQ-LEARNING-RULES-1.3.0`，日期 2026-11-19。
- 本版在[教学规则 1.2](LEARNING_RULES_V1_2.md)基础上更新“同五行、太少相同”一项。相生、相克、同五行太少不同及其余条目沿用 1.2。
- 授权依据为 [E5 任务卡](../docs/plans/2026-11-18-stage-facts/cards/E5-same-state-label.md)及用户于 2026-11-19 转述的专家答复。
- 专家已确认当步主客运关系的全部标签。五步运交运仍为“教学口径，待专家确认”。
- `YQ-API-CONTRACT-1.3.0` 中的 `traditionalLabel` 和 `ruleVersion` 继续使用字符串。精确比对版本或文案的消费方须迁移到 `YQ-LEARNING-RULES-1.3.0` 和本版标签。

## 1. 专家答复（用户转述，2026-11-19）

> 如果合并显示，太少不同的只需说“五行相同、太少不同”；另一种就说“五行相同、太少相同”。如果合并显示麻烦，也可以直接完整显示。

侧栏采用“同属{element}运 · 太少相同”，使同五行的两种标签使用相同句式，适合 400px 面板。标签用于描述当步主客运结构。
